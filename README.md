# Aplena

**按月看清个人财务事实，并判断未来还能承担多少。**

Aplena 是一款本地优先的个人财务承载力桌面软件。它把本月收入、支出、退款与冲减组织成可核对的月度结果，再用总览和历史趋势回答两个问题：这个月实际发生了什么，现有财务结构是否仍有余量。

它不是传统流水账，也不要求先建立长期计划。首次打开会以人民币作为本位币直接进入应用；你可以从一项本月收入或支出开始，之后再按需要配置下月预算和周期规则。

## 产品定位

### 为什么需要 Aplena

日常财务软件常把注意力放在每笔交易、账户余额或分类流水上，但真正影响长期决策的往往是月度结构：稳定收入能否覆盖必要支出与固定承诺，本月结余是否符合预期，以及新增一项长期支出后还剩多少安全空间。

Aplena 以月份为基本工作单位，将真实结果、可选预算基准和历史变化放在同一套口径下。用户不必每天记账，也不需要为了看报表维护账户、商户或复式分录。

### 与传统记账的区别

```text
本月收入 / 支出 / 退款 / 冲减
                ↓
          月度执行与核对
                ↓
       总览 · 历史趋势 · 储蓄率
                ↓
      为下一个自然月配置预算
```

- 实际数据以月度项目下的可解释条目组成，不保存可随意修改的月度总额。
- 计划只提供比较基准；没有周期规则也能完整记录和查看实际财务结果。
- 下月预算只作用于下一个自然月，不改写当前月或历史月。
- Aplena 不提供云账户、银行同步、交易导入、备份恢复或可读导出。

## 围绕月份工作

### 总览

打开应用即可看到本月实际收入、支出、净结余与储蓄率，以及计划对比、重要偏差、分类结构和历史趋势。尚未完整核对的月份会明确标注“当前已录”，不会把缺失数据伪装成零。

### 月度执行

月度执行用于创建本月项目、逐笔添加实际条目并在月末确认。支出可以追加退款，收入可以追加冲减；条目支持编辑和删除，任何变化都会让已确认项目重新进入待核对状态。

每笔外币实际会保留原币金额、当次换算汇率、来源与参考日期。后续汇率更新不会回算已经发生的费用。

### 配置下月预算

“配置预算”只面向下一个自然月。你可以设置最低储蓄率，并按需要添加周期规则，用于自动生成后续月份的计划基准和计算财务承载力。周期规则是增强项，不是开始使用 Aplena 的前置条件。

### 历史报表

历史报表按年份展开已有月份，并可进入任意月份查看分类、项目、储蓄率与趋势。历史快照不会因后来修改预算、周期规则或汇率而变化。

## 产品原则与数据边界

### 本地优先

Aplena 是单用户、单账本的本地桌面应用，不需要登录，也不会把财务数据上传到云服务。网络仅用于按需读取欧洲央行每日参考汇率；断网时仍可使用本位币和已经保存的备用汇率。

首个版本使用受操作系统用户权限保护的本地 SQLite 数据库，目录与数据库相关文件限制为当前用户访问。数据库文件本身未做静态加密，因此不能把 Aplena 描述为端到端加密产品；建议在设备上启用 FileVault，并妥善保护本机账户。

### 稳定的财务口径

- 本位币默认人民币，可在尚未形成月度事实前修改。
- 金额以固定两位精度保存，汇率保留八位精度。
- 计划快照一旦进入某个月份便保持冻结。
- 实际净额由增加条目减去退款或冲减条目实时派生。
- 无收入等零分母场景显示为不可计算，不制造无效比例。

### 清晰的功能边界

Aplena 关注个人财务事实、月度执行和承载能力，不提供账户余额管理、自由流水、商户系统、会计分录、银行同步或独立“财务分析”模块。详细分析已经融入总览和每个月的历史报告。

## 获取与使用

### 系统要求与下载

首发目标为 macOS 11 及以上版本。正式版本通过严格的 `vMAJOR.MINOR.PATCH` 标签构建；双架构远程流水线验证通过后，可在 [GitHub Releases](https://github.com/Morton-Li/Aplena/releases) 下载 Apple Silicon 与 Intel 安装包。

GitHub Actions 发行流程配置为使用项目的 “Morton Li” 自签名证书并校验证书指纹，但它不属于 Apple Developer ID 信任链，也未经过 Apple 公证；macOS 可能在首次打开时显示安全提示。本地自行构建的应用仅使用系统默认的 ad-hoc/linker 签名。

### 第一次打开

应用没有启动向导。首次打开会默认使用人民币并直接进入总览；前往“月度执行”创建第一项收入或支出即可开始。若需要外币，在录入时直接选择支持币种，或先在“设置”更新官方参考汇率。

### 本地数据说明

数据保存在当前 macOS 用户的应用数据目录。Aplena 当前不提供内置备份、恢复或导出能力，卸载、清理应用数据或迁移设备前请先了解这一边界。开发期数据库与首个正式版数据库采用不同兼容边界，不能直接混用。
