# ADR-0011：以周期规则直接派生下月预算结果

状态：接受

## 背景

独立储蓄率被命名为“目标”，但配置预算页同时允许修改决定结果的周期规则。若储蓄值也由这些规则动态计算，它表达的是预计结果而不是外部约束；继续保留“剩余承载能力”和“最大承载能力”会为没有独立安全边界的数值制造确定性。原预算类型饼图还把收入与支出放在同一分母中，比例不利于解释。

## 决策

1. 删除 `NextMonthGoal` 聚合、相关 IPC 和 `next_month_goal` 表；schema 3 直接删除旧目标数据，不提供兼容读取。
2. `BudgetProjection` 只读取后端计算的下一个自然月、有效 `PlanItem` 及汇率，按月度等价金额派生预计收入、预计支出、预计储蓄和预计储蓄率。
3. 预计储蓄允许为负并作为缺口展示；预计收入为零时储蓄率为不可计算，不制造无效比例。
4. 固定承诺占稳定收入比例和稳定收入覆盖倍数作为辅助指标保留，不再输出保留能力、最大能力或最低储蓄金额。
5. 配置预算页把下月预算概览和三类支出占比放在同一行；饼图不混入收入。
6. 图表与精确数据采用固定高度翻转面，数据过多时在背面内部滚动，并提供减少动态效果和不可聚焦隐藏面的可访问行为。

## 后果

- 周期规则是下月投影与后续月度快照的唯一计划来源；修改规则仍不会回写当前月或历史月。
- 投影回答“按现有规则预计会怎样”，不再回答缺少外部储蓄政策时无法客观定义的“还能花多少”。
- 总览柱状图在绘图层把缺失值显示为零；历史折线只把已结束月份的缺失点补为零，当前月和未来月份仍以 `null` 断线。权威分析与精确数据始终保留 `null` 语义。
- ADR-0009 的目标聚合决策被本 ADR 取代。
